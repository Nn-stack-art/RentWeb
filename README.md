这是一个租房系统，使用python爬取链家网站的数据，并存入mongodb数据库中，前端是html5，后端是springboot框架。
1.ForPython文件夹里有爬取链家网站的代码和爬取的数据
2.SQL文件夹里有数据库中表的结构
3.springboot里是后端的代码
4.如果要使用此项目的话，记得去百度申请申请api，才能实现百度地图的功能
